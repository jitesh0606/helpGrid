# 🌍 HelpGrid

### Connecting people who need help with verified organizations that can respond.

HelpGrid is a location-aware community assistance platform designed to connect individuals with verified NGOs based on **help category, location, availability and service capacity**.

Instead of sending a help request to every organization at once, HelpGrid uses a **controlled sequential NGO dispatch system** where a suitable NGO receives the request first. If the NGO rejects the request or its response window expires, the request can move to the next suitable NGO.

The platform also provides **real-time communication, notifications, request tracking, NGO verification and nearby NGO discovery**.

---

## 🚀 Why HelpGrid?

In real-world situations, finding the right organization for a specific need can be difficult.

A person may need:

- 🍱 Food
- 👕 Clothes
- 🏥 Medical assistance
- 📚 Education support
- 🏠 Shelter
- 🚑 Emergency assistance
- 📦 Other resources

At the same time, NGOs may have different:

- Service areas
- Categories they support
- Availability
- Capacity
- Response times

HelpGrid connects these two sides through a centralized platform.
